# P0 — 执行前产品与兼容决策门

> 本阶段只提问和记录选择，不修改源码、测试或文档。
> Executor 必须先把下列问题发给主人；主人回复“按推荐项执行”即可一次性采用所有推荐项。

## 必须确认

1. 数据库备份兼容

   - 推荐：严格要求当前核心表/列/关键约束，允许缺 `listening_stats`；未知旧 schema 拒绝并提示，不自动猜迁移。
   - 备选：需要兼容更老备份。选择后先暂停 P2，另做 schema 版本/迁移审计。

2. Range 超出文件尾

   - 推荐：显式 end ≥ 文件大小或 suffix 长度 > 文件大小都返回 416，匹配当前 `harness/CONSTRAINTS.md`“越界必须拒绝”。
   - 备选：按 HTTP 通常语义夹到文件尾。选择后必须先更新 Harness 决策和测试合同，不能代码/约束互相冲突。

3. 音频失败后的行为

   - 推荐：停留当前歌曲，显示持续错误提示，由用户选择重试或下一首；不自动跳过、不无限重试。
   - 备选：自动跳过坏歌。选择后必须另定连续坏歌上限和终止条件。

4. Retry 从哪里恢复

   - 推荐：同 Track 最后一个有限、非负位置；从未成功加载时从 0 开始。
   - 备选：所有失败一律从 0 开始。

5. 错误提示覆盖范围

   - 推荐：普通、歌词、Mini 三个壳层共用一个根级紧凑 banner，Mini 窗口尺寸不变。
   - 备选：分别嵌入各播放器；选择后需要单独视觉方案。

6. Error Boundary 恢复

   - 推荐：显示本地恢复页并完整 reload Renderer，避免在未知半损坏状态中局部续跑。
   - 备选：只重建 React 子树。选择后需定义哪些模块级单例/监听器必须重置。

7. Media Session 更新时机

   - 推荐：立即更新文字，封面异步补齐；两次提交都遵守 latest-wins。
   - 备选：等封面完成后一次性更新，接受文字延迟。

8. Liked 取消收藏提交时机

   - 推荐：IPC 成功后移除页面行；失败保持现状。
   - 备选：乐观移除，失败回滚。选择后需增加回滚和重复点击规则。
