## 问题

排序触发器按钮太长（固定172px），文字左对齐，视觉上不够紧凑。

## 目标

按钮改小一点，文字居中显示。

---

## 改动范围

| 文件 | 改动 |
|------|------|
| `src/styles/albums.css` | 调整触发器宽度和文字对齐 |

---

## 实现

当前样式（第48-64行）：
```css
.album-sort-menu__trigger {
  width: 172px;
  height: 32px;
  /* ... */
  text-align: left;
}
```

改为：
```css
.album-sort-menu__trigger {
  width: auto;
  min-width: 120px;
  height: 32px;
  /* ... */
  text-align: center;
}
```

**⚠️ 注意：**
- `width: auto` 让按钮宽度自适应文字内容
- `min-width: 120px` 保持最小宽度，防止太窄
- `text-align: center` 让文字居中
