# QinPlayer 开发日志 - 2026-07-06

## 歌词界面增强

### 背景
主人对歌词界面有两个增强需求：进度条加粗、添加音量按钮和播放方式按钮。

### 改动内容

#### 1. 歌词界面进度条加粗
- 从 `0.4vh` 改成 `8px` 点击热区 + `4px` 轨道/填充
- 复用主页面进度条结构（bar 负责命中区域，::before 画轨道，fill 画填充）

#### 2. 歌词界面添加音量按钮
- 新增 `showVolume` 状态、`volumeRowRef`、`volumeBarRef`
- 点击外部收起（useEffect + mousedown + contains 判断）
- 音量按钮点击（stopPropagation）
- 音量拖动（updateVolume、handleVolumeMouseDown）
- 竖向音量条（width: 8px, height: 100%, fill 从 bottom: 0 开始）
- 音量图标根据音量切换（IconVolumeMuted/IconVolumeLow/IconVolumeHigh）

#### 3. 歌词界面添加播放方式按钮
- 复用主页面逻辑（togglePlayMode）
- 图标切换：IconRepeat/IconRepeatOne/IconShuffle
- 用 `position: absolute` 定位在左侧，不参与居中计算

#### 4. 按钮布局调整
- 当前：[上一首] [播放/暂停] [下一首]
- 改成：[播放方式] [上一首] [播放/暂停] [下一首] [音量]
- 三个播放按钮单独居中，播放方式和音量按钮左右对称放置

### 验证

- npm run build：通过

### 文件改动
- `src/pages/Lyrics.tsx` — 添加音量按钮、播放方式按钮、布局调整
- `src/styles/lyrics.css` — 进度条加粗 + 音量弹窗/音量条样式
