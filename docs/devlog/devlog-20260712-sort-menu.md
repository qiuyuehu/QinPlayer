# Devlog — 2026-07-12 通用排序菜单与歌曲排序

## 功能

- 将专辑专用排序菜单泛化为类型安全的 `SortMenu<T>`，动态接收字段并为每个实例生成唯一 popup ID。
- 本地音乐与我喜欢的页面支持按歌名、歌手、播放次数升降序排列。
- 页面把当前排序结果传给 `SongList`，因此从页面起播后的队列顺序与可见顺序一致。

## 边界

- 排序状态不持久化，页面重新挂载后恢复歌名升序。
- 不修改 `SongList`、后端查询和专辑详情中的歌曲源顺序。
- 空值、未知歌手和非有限播放次数始终位于末尾；并列项按歌名、歌手、ID 升序决胜。

## 测试

- 定向测试：`5` 个测试文件、`23` 个用例通过。
- `npx tsc --noEmit` 通过。
- 批次 A 完整 `npm run verify` 通过：`42` 个测试文件、`385` 个用例。
- 隔离数据库无法在当前授权额度下写入虚拟歌曲，因此有数据页面的排序菜单视觉效果留给主人确认。
